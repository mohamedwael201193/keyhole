## Scope and production prerequisite

The production adapter requires **`INTENTS_READ_API_KEY`** for the documented read-only solver-relay status endpoint before a new exit can be admitted. It never treats an invented OutLayer `tx_hash` field as supported; OutLayer same-chain output remains `{intent_hash, delivered}`. An optional fresh holder-signed `original_delivery_locator` supplies only an untrusted historical RPC routing hint; the complete receipt/event proof must still independently match the immutable original intent, wallet, recipient, asset and exact amount. See [provider references and recovery procedure](../../../../worker/EXACT_NEAR_EXIT.md).
